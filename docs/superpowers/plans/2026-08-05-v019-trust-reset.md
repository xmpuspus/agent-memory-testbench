> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a local v0.1.9 trust reset. Fix known evidence defects, mark bundled v0.1.8 data historical, and remove silent result substitution. Add the new display name without breaking compatibility.

def _primary_raw_score(record: dict) -> float | None:
